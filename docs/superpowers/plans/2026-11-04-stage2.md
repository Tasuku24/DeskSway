# DeskSway Stage 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build the local menu-bar app described in the approved stage 2 design.
**Architecture:** A pure input policy and validated preferences own conversion invariants. A native adapter owns CGEvents, a background AX reader owns detection, and AppKit owns lifecycle and menus. Reuse the probe's bounded traversal in a shared source file.
**Tech Stack:** Swift Package Manager, AppKit, ApplicationServices, XCTest; no dependencies.
**Spec:** `docs/stage2-design.ja.md`

## Global Constraints
- Work on main as requested. No push, publication, license choice, login item, BTT uninstall, or other app setting changes.
- First launch paused; persistent run preference cannot override missing permissions, stale/unknown detection, or disabled tap.
- AX polling 200 ms target; freshness 500 ms measured from scan start; limits depth 4, 200 elements, IPC timeout 150 ms.
- Wheel burst ends after 250 ms without horizontal input; movement interval at least 600 ms; preserve vertical components.
- Public CGEvents cannot authenticate a physical mouse. Initially accept only phase-less, non-momentum wheel-style events; continuous phase-less events remain eligible for mouse smoothers. Document this compatibility limit.
- Build/test success is not physical mouse acceptance. Do not silently start converting the user's input.

## Review Focus
- Stale AX results arriving after sleep or process replacement must not re-arm conversion (generation token).
- Mixed events must keep every vertical representation when horizontal values are stripped (real CGEvent tests).
- Permission, construction, or tap failures must return the original event (policy/adapter tests).
- A held wheel burst must not generate repeats even after cooldown; a cooldown-blocked burst stays blocked (timeline tests).
- Invalid persisted shortcuts must fail open, never silently execute default keys (preferences tests).
