# DeskSway v0.2.0-beta.1

ログイン時の自動起動を設定画面から切り替えられるようになりました。

## 変更点 / Changes

- 「一般 → ログイン時に起動」で自動起動のオン・オフを切り替えられます。保存不要で即時反映されます。
- macOSが管理するログイン項目の状態を表示し、承認が必要な場合はシステム設定を開けます。変更に失敗した場合はエラーを表示します。
- 初回起動時にログイン項目を自動登録することはありません。
- 設定画面の高さを調整し、自動起動の説明文や見出しがつぶれないようにしました。

- Added **General → Launch at login**, applied immediately without Save.
- Shows the macOS login-item status, provides an **Open Login Items…** button when approval is required, and reports registration errors.
- Login at startup remains opt-in. Opening the app does not register a login item.
- Increased settings height to keep headings and launch-at-login guidance readable.

## インストール / Install

Download **DeskSway-0.2.0-beta.1-macos-arm64.zip** from Assets, extract it, quit the previous DeskSway, and move the new **DeskSway.app** into Applications. The ZIP includes Japanese and English instructions in `INSTALL.md`. GitHub's automatic “Source code” archives do not contain a built app.

配布用ZIPを展開し、起動中のDeskSwayを終了してから、新しいアプリを「アプリケーション」に移動してください。既存の設定は通常保持されます。この仮署名版では入力権限の再登録が必要になる場合があります。

This preview is for **Apple Silicon**, ad-hoc signed, and **not Developer ID signed or notarized by Apple**. macOS may require first-launch approval. Accessibility, Input Monitoring and Key Posting permissions are separate; an update may require granting them again. See [Apple's opening instructions](https://support.apple.com/en-us/102445).

The matching `.zip.sha256` asset contains the archive's SHA-256 checksum.

## Validation and limits

- All 57 automated tests passed, including launch-at-login state, immediate application, failure recovery, and settings layout checks for approval guidance, light/dark appearances and resizing.
- The release ZIP was extracted and checked for its app version, Apple Silicon architecture, ad-hoc signature, license, installation guide, English/Japanese resources and Service Management linkage.
- Actual launch after logging out and back in, and installation on another Mac, have not been independently verified.
- Built on macOS 27.2.1. The macOS 14 deployment target does not establish compatibility with every OS version, Intel Mac or input device.
- Mission Control detection relies on system UI structure, and public scroll events cannot reliably identify a physical mouse. Quit BetterTouchTool before enabling DeskSway.
- Automatic updates are not included. To return to the previous preview, turn off Launch at login, quit DeskSway, and reinstall the previous release ZIP.
