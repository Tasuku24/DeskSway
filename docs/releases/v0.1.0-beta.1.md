# DeskSway v0.1.0-beta.1

First public preview of DeskSway, a native macOS menu-bar app that turns horizontal mouse scrolling into Space shortcuts while Mission Control is detected.

## Download and install

Download **DeskSway-0.1.0-beta.1-macos-arm64.zip** from this release's Assets. Extract it, move DeskSway.app to Applications, and open it. The included INSTALL.md has Japanese and English setup instructions. GitHub's “Source code” archives are for building the app yourself.

This free preview is ad-hoc signed and is **not Developer ID signed or notarized by Apple**. macOS may block its first launch. If you trust the source, follow [Apple's Open Anyway instructions](https://support.apple.com/en-us/102445). Accessibility, Input Monitoring and Key Posting permissions are required separately. Replacing an ad-hoc build may require granting permissions again.

The matching `.zip.sha256` file provides the archive's SHA-256 checksum.

## Included

- Horizontal scroll conversion while Mission Control is detected, with pause and permission status in the menu bar.
- Direct recording of left/right shortcuts and horizontal scroll directions.
- Repeat delay from 0.00 to 2.00 seconds, defaulting to 0.60 seconds.
- English and Japanese settings with General and Permissions tabs.
- Custom app and menu-bar icons.
- MIT license, included in both the download and app bundle.
- Fixed invalid initial tab geometry and conflicting layout constraints.

## Validation

All 54 automated tests passed. Settings layout checks cover both tabs, light/dark appearances and resizing; detailed AppKit diagnostics reported no layout warnings. The Release ZIP was extracted and its ad-hoc signature, bundled license, English/Japanese resources and icons were verified. Installation after download on another Mac has not been independently verified.

## Compatibility and limits

- This download is for **Apple Silicon**. Manual acceptance has been completed by the maintainer in their environment; the recorded macOS environment is **27.2**. Other macOS versions, Intel Macs and other hardware combinations are not guaranteed.
- The deployment target of macOS 14 is not a compatibility claim for every later macOS version.
- Mission Control detection depends on system UI structure and may change with macOS updates.
- Public scroll events cannot reliably distinguish a physical mouse from a trackpad or mouse-smoothing software that generates the same event format.
- Quit BetterTouchTool before enabling DeskSway. Startup at login and automatic updates are not included.
- If input behaves unexpectedly, pause or quit DeskSway. Report the macOS version, mouse model, smoothing software and reproduction steps in GitHub Issues.
